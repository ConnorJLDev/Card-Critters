## File Location
Following these steps will allow you to view and modify the contents of the template files in the Visual Studio projects.

* After unzipping the contents of the .zip file:
  * Rename the folder containing the template materials to "Templates".
  * Move the "Templates" folder adjacent to the "Project 1" folder.

## Installing VS Templates:

* Double-click on InstallTemplates.bat.
  * You may need to modify the destination name, as per the instructions provided in the .docx file.
* Restart Visual Studio
